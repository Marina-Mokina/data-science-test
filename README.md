# Data Science Test

Тестовое задание на позицию Data Science Developer.

## Описание

Проект обрабатывает текстовые записи тьютора о детях с инвалидностью и выполняет три задачи:

1. извлечение структурированной информации из записи;
2. классификация типа записи;
3. определение, относится ли наблюдение к одной из отслеживаемых зон развития.

## Реализация

### 1. Извлечение информации

Функция `extract(text: str) -> dict` извлекает:

* дату;
* ID ребенка;
* автора записи;
* продолжительность сна в часах;
* явно указанную зону.

Поддерживаются форматы дат и продолжительности сна, указанные в задании.

### 2. Классификация записей

Функция `classify(text: str) -> tuple[str, float]` определяет один из типов:

* `observation`
* `lesson_report`
* `parent_note`
* `recommendation`
* `unknown`

Если разница между двумя наиболее высокими оценками меньше `0.15`, возвращается `unknown`.

### 3. Анализ зон развития

Функция `check_zone(note: str) -> tuple[bool, float, str]` определяет, относится ли наблюдение к одной из зон:

* эмоции
* коммуникация
* поведение
* питание
* сенсорика
* сон
* моторика
* самообслуживание

Для семантического анализа используется локальная модель **qwen2.5:7b-instruct** через Ollama.

При недоступности LLM используется резервный механизм на основе ключевых слов, позволяющий выполнить анализ без API-ключа и запущенной модели.

Внешний API не используется.

## Установка

Требуется Python 3.11+.

```bash
pip install -r requirements.txt
```

Для анализа зон необходимо установить Ollama и загрузить модель:

```bash
ollama pull qwen2.5:7b-instruct
```

## Запуск

```bash
python main.py
```

После запуска автоматически создаются:
- `results.json` — структурированный JSON-отчет с результатами обработки и confidence score;
- `RESULTS.md` — итоговый отчет по тестовым данным.
